# pop-density-lab

Учебная лабораторная работа по плотности населения: сравнение стран и городов,
историческая динамика 1960–2026, калькулятор плотности и экспорт в CSV.

Стенд собран на **Go + Hydrogen (H2O)**: Hydrogen отдаёт статику и проксирует
`/api/*` в Go-сервис, Go считает плотность и хранит датасет.

## Стек

| Слой | Технология |
| --- | --- |
| Статика и reverse proxy | Hydrogen / H2O (HTTP/2) |
| REST API | Go 1.23, только стандартная библиотека (`net/http`) |
| Frontend | HTML + CSS + vanilla JS, Chart.js 4 (локально, без CDN) |
| Оркестрация | Docker Compose |

## Запуск на другом компьютере

В GitHub лежит только код — сайт не захостен. На новом компьютере проект нужно
склонировать и собрать локально. Понадобятся **Git** и **Docker Desktop**
(Windows/macOS) или **Docker Engine + Compose v2** (Linux). Первая сборка
скачивает образы и компилирует H2O, поэтому нужен интернет.

### 1. Клонировать репозиторий

```bash
git clone https://github.com/linzaiq-afk/pop-density-lab.git
cd pop-density-lab
```

### 2. Запустить контейнеры

```bash
docker compose up -d --build
```

На Windows предварительно запустите Docker Desktop и дождитесь, пока он
перейдёт в состояние Running. Docker Desktop должен работать в режиме
**Linux containers** (это режим по умолчанию). Первая сборка занимает
несколько минут: H2O компилируется из исходников. Последующие запуски
используют кэш Docker.

### 3. Открыть сайт

- приложение — <http://localhost:8080>
- API — <http://localhost:8080/api/entities>
- проверка — <http://localhost:8080/api/health>

Проверить, что оба контейнера поднялись:

```bash
docker compose ps
```

Ожидаемый статус — `Up ... (healthy)` у `pop-density-go` и
`pop-density-hydrogen`. Если Hydrogen ещё `health: starting`, подождите
10–15 секунд.

### Остановка и обновление

```bash
docker compose down          # остановить
docker compose up -d         # запустить снова без пересборки
git pull                     # обновить код
docker compose up -d --build # пересобрать после обновления
```

### Открыть с другого устройства в той же сети

Docker публикует порт на всех интерфейсах (`0.0.0.0:8080`), поэтому с телефона
или второго компьютера в той же Wi-Fi/локальной сети можно открыть:

```text
http://<IP-компьютера-с-Docker>:8080
```

IP на Windows: `ipconfig` → «IPv4-адрес» активного адаптера. Если страница
не открывается, разрешите порт 8080 в брандмауэре Windows или в настройках
роутера. Сам `localhost` с другого устройства не работает — он указывает на
само это устройство.

### Режим без Docker (только Go)

Если Docker нет, но установлен Go 1.23+, можно запустить API и статику одним
Go-процессом (Hydrogen в этом режиме не участвует):

Windows PowerShell:

```powershell
cd backend
$env:STATIC_DIR = "..\frontend"
$env:LISTEN_ADDR = ":8081"
go run .
```

Linux/macOS:

```bash
cd backend
STATIC_DIR=../frontend LISTEN_ADDR=:8081 go run .
```

Затем откройте <http://localhost:8081>.

### Важно про хостинг

Репозиторий на GitHub — это исходники, а не работающий сайт. Ссылка
`http://localhost:8080` работает только на том компьютере, где запущен Docker.
Чтобы получить публичный адрес, проект нужно развернуть на сервере/VPS
(достаточно установить Docker и выполнить те же две команды) либо сделать
статическую версию и выложить её на GitHub Pages.

## API

| Метод | Путь | Описание |
| --- | --- | --- |
| `GET` | `/api/health` | Состояние сервиса |
| `GET` | `/api/meta` | Годы, количество стран и городов |
| `GET` | `/api/entities` | Все объекты с историей |
| `GET` | `/api/entities?type=city` | Только города (`country` — страны) |
| `GET` | `/api/entities?q=Москва` | Поиск по названию или стране |
| `GET` | `/api/entities/{id}` | Один объект, например `/api/entities/msk` |

Пример ответа:

```json
{
  "id": "msk",
  "name": "Москва",
  "type": "city",
  "country": "Россия",
  "history": [
    {
      "year": 2026,
      "population": 13250000,
      "area_km2": 2561.5,
      "density": 5172.75
    }
  ]
}
```

Плотность считается на бэкенде по формуле:

```text
ρ = N / S,   чел./км²
```

где `N` — население, `S` — площадь. Значение округляется до сотых.

```bash

```

Откройте <http://localhost:8081>. В этом режиме Hydrogen не участвует,
но API и фронтенд работают с тем же кодом.

Тесты:

```bash

go vet ./...
```

Можно также открыть `frontend/index.html` напрямую: фронтенд обратится к
`http://localhost:8081` (CORS на бэкенде разрешён), если API запущен.

## Данные

Датасет демонстрационный: округлённые оценки населения и площади для
8 стран и 9 городов на 1960, 1980, 2000, 2020 и 2026 годы. Он предназначен
для учебного сравнения и не является официальной статистикой.

Площади городов даны в современных границах или в границах соответствующего
периода. Из-за расширения административных границ (например, Новая Москва
в 2012 году) плотность может снижаться даже при росте населения — это
ожидаемое поведение модели, а не ошибка расчёта.

Чтобы расширить набор, добавьте объект в `getDataset()` в `backend/data.go`.
Плотность пересчитается автоматически при старте. Если нужна загрузка
реальных CSV (World Bank, Росстат), логику импорта стоит добавить в
`backend/data.go` и вызывать её из `main.go` до создания `apiServer`.

## Что умеет интерфейс

- фильтр по странам/городам и поиск;
- выбор любого набора объектов для графика;
- линейная и логарифмическая шкала (полезно при сравнении Москвы и России);
- подсказки с населением и площадью за выбранный год;
- сводная таблица с приростом плотности за 1960–2026;
- клик по строке таблицы добавляет объект на график;
- калькулятор `ρ = N / S` с подстановкой данных объекта;
- экспорт текущей выборки в CSV (Excel-совместимый, с BOM).

## Troubleshooting

**Порт 8080 занят.** Измените левую часть в `docker-compose.yml`:
`"9090:8080"`, затем откройте <http://localhost:9090>.

**`docker compose` не видит файлы на Windows.** Убедитесь, что диск с проектом
доступен в Docker Desktop (Settings → Resources → File sharing).

**Сборка Hydrogen падает на `git submodule`.** Проверьте доступ к GitHub;
H2O тянет субмодули (picotls, mruby и др.). Можно зафиксировать проверенную
версию: `docker compose build --build-arg H2O_REF=<tag> hydrogen`.

**API отвечает 502.** Go-контейнер ещё не прошёл healthcheck или упал:
`docker compose logs go-backend`.
